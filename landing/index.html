What is TormentNexus?

TormentNexus is a next-generation engineering environment that combines the best features of modern terminals, IDEs, and AI-agentic harnesses. Built on open web standards with a high-performance Go backend, it provides a seamless and autonomous experience for both humans and AI agents.

Core Features

  • Continuous Autonomous Execution: Designed for total autonomy.
  • Unified Interface: Cohesive experience for terminal, code, and AI.
  • Native MCP Support: First-class Model Context Protocol server and client.
  • Deep Integration: Consolidation of Tabby, Warp, Hermes-Agent, and more.
