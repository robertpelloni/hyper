# TormentNexus Ideas

- **Semantic Command Blocks:** Track stdout/stderr streams per shell prompt to allow direct conversation with past terminal outputs.
- **Embedded MCP Stdio Bridge:** Allow invoking local CLI tools (e.g. `rg`, `git`, `docker`) as standard MCP tools without manual wrapping.
- **Interactive Notebook Canvas:** Allow rendering markdown tables, charts, and interactive web elements directly inside terminal responses.
- **Agent Memory Stream:** Persist Think-Act-Observe traces to SQLite for multi-session reasoning retention.
- **Cross-Platform System Tray Menu:** Native notification center integration when long-running agent tasks complete.
