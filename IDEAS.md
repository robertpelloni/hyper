# TormentNexus Ideas

- **Warp-like Command Blocks:** Implement deep integration between terminal output and LLM context using the `internal/terminal/buffer.go` logic.
- **Wave-like Notebook Interface:** Allow rendering markdown and interactive widgets directly in the terminal stream.
- **MCP Tool Integration:** Automatically discover and register local MCP servers for the agent harness.
- **SSH Agent Forwarding:** Enhance `internal/session/remote.go` to support secure identity management.
- **Multi-Language WebUI:** Provide a WebUI that has feature parity with the TUI/CLIs, serving as the central hub for the 5 multi-language builds (TypeScript, Rust, Go, C#, Java).
- **Universal Browser Extension:** Act as an MCP server for ChatGPT, Gemini, Claude, Grok, etc., while managing local memories across language stacks.
